## 🎯 Описание проекта

**ChatFlow Automator** — это система автоматизации взаимодействия с веб-чатами через браузер. Проект предоставляет возможность автоматизированного запуска последовательностей задач (карточек) с поддержкой множества чат-платформ: ChatGPT, Claude, GenSpark, Qwen и других.

### Основной функционал:
- 🌐 Автоматизация взаимодействия с чат-интерфейсами через Playwright
- 🔐 Управление cookies и поддержка прокси (HTTP/HTTPS/SOCKS5)
- 📝 Редактирование последовательностей задач через GraphicalUI (PyQt6)
- 📊 Экспорт результатов в JSON, Markdown, CSV форматах
- ⚙️ Асинхронное выполнение задач с логированием
- 🔗 Поддержка переменных и взаимозависимых задач
